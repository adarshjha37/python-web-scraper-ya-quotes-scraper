# 🐍 Python Web Scraper (Quotes & Authors)

A lightweight and fast Python web scraping tool built with `BeautifulSoup` and `requests`. It automatically fetches quotes and author details from a target website and exports them into a clean CSV file.

## ✨ Features
- Extracts quote texts and author names automatically.
- Saves clean data directly into `scraped_quotes.csv`.
- Error handling included for network requests.
